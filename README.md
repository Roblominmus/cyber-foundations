# cyber-foundations

Course material for the Cybersecurity Foundations track.

This repo exists because a lot of the good material for this track is either
locked behind a subscription or scattered across writeups. Anything the track
needs that does not have a solid free link lives here instead, so students can
read it and practise it without paying for a room or hunting for a tutorial.

## About this material

This repo was assembled with AI, working from the raw notes of
[Roblominmus](https://github.com/Roblominmus). The technical content comes from
those notes and from the sources they link to.

Because of how it was built, some of the prose may read a little mechanically.
Pardon that. Treat every page as notes from someone who did the work, tidied up
by a machine, not as a polished textbook.

If you need help, get stuck, spot something wrong, or want to tell me anything
about the material, contact me directly rather than guessing. Questions are
welcome, and being stuck is normal. It is the fastest way to find the gaps in
these pages.

## Rules for this repo

- Read first, then do. Every page ends with something to actually run.
- No page is only reading. If there is nothing to test it against, it does not
  belong here.
- Answers live in `solutions.md` files. They are not hidden, they are just in
  their own note. Try the work first.

## Licence and use

This is teaching material for a private study group. The practice hashes are
generated for this repo and are safe to crack. Never submit a hash you found on
a real engagement to a public cracking site without written permission from the
client, because you are handing them the hash and the plaintext.
